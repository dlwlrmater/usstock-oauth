usstock 隐私说明 / Privacy Policy

Last updated: 2026-10-09. This notice describes the owner-operated personal Google Drive utility, not a public registration service.

Purpose and access / 用途及访问范围

The utility uses Google OAuth, Google Drive API and local file-processing tools to archive and organize files in accounts explicitly authorized by their owners. Depending on granted permissions and owner settings, it reads file metadata and authorized file contents, downloads permitted files, uploads copies, and manages sharing restrictions. It does not grant access to other accounts without authorization.

Storage / 数据保存

Authorization credentials are stored in the owner's local application configuration. Working copies, diagnostic files and logs may be stored on the owner's computer. Archived files remain in the Google Drive account selected by the owner. No credentials, file contents or private diagnostic logs are published to this GitHub repository or website.

Transfers and optional processing / 数据传输及可选处理

Files and metadata are sent to Google when necessary for the requested Drive operations. If the owner enables additional file processing, AI-assisted processing or link notifications, relevant content or links may be sent to the selected processing or messaging provider. These providers have their own privacy policies. This public site is hosted by GitHub Pages; GitHub may process ordinary website access logs. The site has no Google login form or application token collection.

Control and deletion / 控制与删除

The owner can revoke this application's access in Google Account security settings, remove local credentials and working files, and delete archived files or change sharing in Google Drive. Revoking access stops future authorized API access; it does not itself delete previously saved copies. Retention of files and logs is controlled by the owner.

Support / 联系

Contact the operator through GitHub issues. Do not post credentials or private documents in public issues.
